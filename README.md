# Auto Layout для Photoshop

**Auto Layout** автоматически раскладывает выбранные слои внутри выделенной области Photoshop: подбирает количество и наполнение рядов, общий масштаб фотографий и интервалы между ними. Скрипт рассчитан прежде всего на групповые и школьные макеты, но может работать и с обычными фотографиями, рамками и другими прямоугольными объектами.

Базовая геометрическая раскладка работает **без Python**. Python нужен только для расширенного поиска заполнения сложных площадок и для анализа фотографий: пола, направления головы/корпуса и цвета одежды.

Интерфейс скрипта автоматически отображается **на русском или английском** в зависимости от локали Photoshop. Надписи системного progress bar всегда остаются на английском.

## Установка

### 1. Распакуйте архив

Не запускайте установщик прямо из ZIP. Сначала распакуйте весь архив в обычную папку.

### 2. Установите Python-компоненты — если нужны дополнительные функции

Если вам нужна только обычная геометрическая раскладка, этот шаг можно пропустить.

Для функций **«Рассчитывать заполнение площадок в Python»**, **«Чередовать мальчиков и девочек»**, **«Учитывать разворот тела и головы»** и **расстановки по цвету одежды**:

1. Запустите `install_runtime.bat`.
2. Выберите:
   - **1 — Normal secure mode** — обычная установка, рекомендуется;
   - **2 — Kaspersky compatibility** — если Kaspersky мешает загрузке Python-пакетов.
3. Дождитесь сообщения **Installation complete**.

Python устанавливается отдельно от системного Python. Ничего вручную настраивать в `PATH` не требуется.

### 3. Установите скрипт в Photoshop

Скопируйте **содержимое** папки `Photoshop-files` в папку сценариев Photoshop, например:

```text
C:\Program Files\Adobe\Adobe Photoshop 2026\Presets\Scripts\
```

В результате там должны находиться:

```text
Auto-layout.jsx
lib\auto-layout-api.pyw
```

Оставляйте в `Presets\Scripts` только **одну актуальную версию Auto Layout**, иначе в меню Photoshop могут появиться дубликаты.

После копирования файлов перезапустите Photoshop.

### Обновление

При обновлении обычно достаточно заменить JSX и `lib\auto-layout-api.pyw` файлами из нового архива. Если новая версия требует дополнительных Python-компонентов, запустите новый `install_runtime.bat` ещё раз.

## Быстрый старт

1. Подготовьте слои, которые нужно разложить.
2. Создайте в документе область раскладки инструментом **«Прямоугольная область»**.
3. Выделите в палитре Layers все слои, которые должны попасть в раскладку.
4. Запустите **Файл → Сценарии → Auto Layout**.
5. Выберите параметры и нажмите **«Разложить слои»**.

Скрипт использует **один общий коэффициент масштаба для всех выбранных объектов**. Фотографии не растягиваются независимо друг от друга.

# Подготовка выделения

## Обычный прямоугольник

Самый простой и быстрый вариант. Создайте одно прямоугольное выделение — все фотографии будут размещены внутри него.

Для обычного прямоугольника базового JSX-расчёта обычно достаточно. Опция **«Рассчитывать заполнение площадок в Python»** здесь практически не нужна.

## Несколько отдельных площадок

Можно создать несколько раздельных прямоугольных областей в одном выделении. Например, оставить место для учителя, заголовка, логотипа или декоративного элемента.

Auto Layout распределит фотографии между доступными площадками и сохранит один общий масштаб.

Для сложного составного выделения имеет смысл включить **«Рассчитывать заполнение площадок в Python»** — он проверяет больше вариантов распределения.

## Вырезанные области и сложная прямоугольная форма

Поддерживаются формы, собранные из прямоугольников:

- L-, U- и C-образные области;
- отверстия внутри выделения;
- несколько отдельных «островов»;
- прямоугольные вырезы по краям.

### Ограничение

Геометрия должна состоять только из **горизонтальных и вертикальных прямых**. Кривые, диагональные стороны, лассо и произвольные контуры не поддерживаются.

Лучше всего создавать форму обычным инструментом **«Прямоугольная область»**, добавляя или вычитая прямоугольники.

# Какие слои можно раскладывать

Без дополнительной подготовки поддерживаются:

- обычные пиксельные слои;
- векторные Shape Layers;
- Smart Objects.

Одиночный обычный слой или shape-слой **не преобразуется в Smart Object** только ради раскладки.

## Группы

Если выбрана группа, Auto Layout рассматривает её как один объект. Для точного определения фактических размеров скрипт **временно** создаёт Smart Object, но после расчёта возвращается к исходной группе и применяет раскладку уже к ней.

После завершения группа остаётся обычной редактируемой группой: вложенные слои, текст, маски и другие элементы не запекаются в Smart Object. Если внутри есть текстовые слои, их текст может использоваться во время анализа имени, но исходное имя группы при финальной раскладке не заменяется.

## Связанные слои

Связанные слои могут быть обработаны как один объект. Для измерения и анализа из них временно создаётся единый Smart Object, после чего документ возвращается к исходным слоям. Масштаб и перемещение применяются ко всему связанному набору одновременно.

После раскладки исходные слои и их связи сохраняются. Скрипт не оставляет вместо них Smart Object и не создаёт постоянную промежуточную группу, если только отдельно не включена опция **объединять каждый ряд в группу**.

Для надёжной обработки связанные слои должны находиться в одном логическом контейнере. Сложные комбинации, способные повлиять на внешние слои, скрипт намеренно не преобразует автоматически.

## Что лучше подготовить заранее

- снимите блокировку с перемещаемых слоёв;
- не используйте Background как перемещаемый объект — сначала превратите его в обычный слой;
- если сложная группа содержит корректирующие слои, обтравочные маски или особые режимы наложения, убедитесь, что их действие ограничено этой группой.

Если Auto Layout не может безопасно обработать такой набор, он останавливается до окончательного изменения документа.

# Основные настройки раскладки

## Автоматически подбирать количество рядов

Рекомендуемый режим для большинства задач.

Скрипт сам перебирает подходящее количество рядов и старается получить крупные фотографии, хорошо заполнить доступную площадь и избежать неудачных рядов из одного человека, если существует более равномерный вариант.

### Когда использовать

- количество рядов заранее не важно;
- нужно максимально эффективно заполнить лист;
- фотографии имеют разные пропорции;
- используется сложное или разорванное выделение.

## Фиксированное количество рядов

Снимите галочку автоматического подбора и укажите нужное число рядов.

### Когда использовать

- макет должен иметь строго определённую структуру;
- нужно повторить композицию другого листа;
- заранее известно, сколько рядов должно быть в школьной группе.

### Ограничение

Если заданное число рядов физически плохо подходит к выделению и размерам объектов, итоговый масштаб может оказаться меньше. В некоторых случаях такая раскладка вообще не помещается.

# Вертикальный ритм

Это **предпочтение**, а не жёсткое правило. Геометрия и возможность разместить все фотографии имеют более высокий приоритет.

### Авто

Скрипт сам выбирает наиболее удачное наполнение рядов без заданного рисунка.

Это лучший универсальный вариант.

### Шире к центру

Центральные ряды по возможности получают больше фотографий, крайние — меньше.

Подходит для классической групповой композиции с визуально более широким центром.

### Шире к краям

Крайние ряды по возможности получают больше фотографий, центральные — меньше.

Используется для обратного ритма композиции.

### Чередование — длинный сверху

Скрипт предпочитает чередование более длинных и более коротких рядов, начиная с длинного верхнего ряда.

### Чередование — короткий сверху

То же самое, но верхний ряд предпочтительно короче следующего.

### Важно

Ритм не заставляет скрипт создавать плохую или невозможную геометрию. Если размеры фотографий или форма выделения требуют другого распределения, Auto Layout выбирает допустимый вариант.

---

# Выравнивание по горизонтали

## По левому краю

Каждый ряд прижимается к левой стороне доступной площадки.

## По центру

Каждый ряд центрируется внутри своей площадки.

Это режим по умолчанию и обычно наиболее удобный для групповых фотографий.

## По правому краю

Каждый ряд прижимается к правой стороне площадки.

## По ширине

Свободное место распределяется между фотографиями, чтобы ряд заполнял доступную ширину.

В этом режиме горизонтальный интервал рассчитывается **отдельно для каждого конкретного ряда**, чтобы ряд дошёл до обеих границ своей доступной площадки. Поэтому два ряда даже с одинаковым количеством фотографий могут иметь разные интервалы, если суммарная ширина фотографий в них отличается. Заданный минимальный интервал при этом сохраняется.

---

# Интервалы

## Минимальный интервал X

Минимальное расстояние между соседями по горизонтали.

## Минимальный интервал Y

Минимальное расстояние между рядами.

Значения задаются в процентах, поэтому их удобно использовать для фотографий разных исходных размеров.

## Максимальное увеличение

Auto Layout может **увеличивать** интервалы относительно заданного минимума, если это помогает лучше заполнить свободное пространство.

Например, при значении `3` интервал может увеличиваться до трёхкратного минимального значения.

Минимальный интервал является жёстким: скрипт не должен уменьшать его только ради того, чтобы вместить больше фотографий.

# Дополнительные режимы Python

Python-функции можно комбинировать друг с другом. Базовая геометрия при этом остаётся основой раскладки.

Если Python недоступен, Auto Layout по возможности продолжает работу обычной геометрией.

## Рассчитывать заполнение площадок в Python

### Что делает

Проверяет больше вариантов распределения фотографий между рядами и отдельными площадками сложного выделения.

Главная цель — получить максимально крупный общий масштаб при корректном заполнении всех доступных зон.

### Когда особенно полезно

- несколько отдельных площадок;
- отверстия и вырезы;
- фотографии заметно различаются по пропорциям;
- JSX нашёл допустимую, но визуально не самую плотную раскладку.

### Когда можно не включать

Для обычного прямоугольника быстрый JSX-расчёт обычно достаточен.

### Ограничения

Python не меняет саму форму выделения и не может использовать запрещённые области. Он ищет лучший вариант только внутри площадок, которые Auto Layout получил из вашего выделения.

Более широкий поиск **не гарантирует**, что каждый конкретный макет обязательно станет лучше, поэтому этот режим лучше воспринимать как дополнительный оптимизатор для сложных случаев.

Если Python не смог вернуть подходящий результат, скрипт автоматически продолжает обычным способом.

# Чередовать мальчиков и девочек

### Что делает

Auto Layout старается построить шахматное чередование **М/Д/М/Д** внутри рядов и, когда возможно, продолжить чередование между соседними рядами.

Если мальчиков и девочек недостаточно для идеального чередования, алгоритм старается:

1. минимизировать одинаковых соседей;
2. сохранить визуальную симметрию ряда;
3. расположить меньшинство ближе к центральной части ряда;
4. по возможности согласовать чередование соседних рядов.

То есть при невозможности идеальной схемы предпочтение отдаётся симметричной композиции, а не простому накоплению одинакового пола в конце ряда.

## Как определяется пол

Сначала используется имя слоя. Лучше всего, если в названии присутствуют нормальные русские имя и фамилия, например:

```text
Иванов Иван
Анна Петрова
```

Допустим и другой порядок слов. Отчество может помочь при неоднозначном имени.

Если по имени уверенно определить пол не удалось и установлен Python-runtime, скрипт может использовать фотографию.

### Ограничения

- анализ фотографии может ошибаться;
- необычные имена могут остаться неопределёнными;
- если пол части детей неизвестен, идеальная шахматная схема не всегда возможна;
- геометрическая возможность разместить фотографии важнее схемы М/Д.

Если перед вами не фотографии людей, но в именах слоёв есть имена, правило М/Д всё равно может работать по названиям слоёв.

# Учитывать разворот тела и головы

### Что делает

Скрипт анализирует направление головы и корпуса и старается построить более естественную композицию:

- фронтальные портреты предпочитают центральную часть;
- более сильно повернутые люди могут уходить дальше к краям;
- направление учитывается так, чтобы композиция по возможности была обращена внутрь листа.

Голова и корпус оцениваются совместно. Небольшие и ненадёжные повороты влияют слабее.

### Что режим НЕ делает

- не зеркалит фотографии;
- не поворачивает сами слои;
- не изменяет позу человека.

Он только выбирает, **какой фотографии какое место дать**.

### Ограничения

Оценка может быть менее надёжной, если:

- лицо очень маленькое;
- человек сильно обрезан;
- корпус почти не виден;
- человек снят со спины;
- поза необычная;
- лицо закрыто волосами или предметами.

Если надёжное направление определить не удалось, фотография не получает выдуманное направление и участвует в обычной раскладке.

Для разорванного выделения направление оценивается относительно общей композиции листа, а не отдельно для каждого маленького прямоугольника.

# Расстановка по цвету одежды

Доступны три режима.

## Не учитывать

Цвет не влияет на порядок фотографий.

## Согласованные цвета

Скрипт старается размещать рядом фотографии с визуально близкими палитрами одежды, создавая более спокойные цветовые переходы по всему листу.

Цвет оценивается **по всему набору выбранных фотографий**, а не отдельно внутри каждого ряда.

## Максимальный контраст

Скрипт старается увеличить различие цветов между соседними фотографиями.

Режим полезен, когда похожая одежда, наоборот, нежелательно сливается в крупные цветовые пятна.

## Ограничения цветового анализа

Это анализ области одежды под лицом, а не полноценное точное выделение одежды по контуру. На результат могут влиять:

- длинные волосы;
- кожа;
- фон около плеч;
- шарфы и аксессуары;
- очень крупное или очень тесное кадрирование;
- белая одежда на белом фоне.

Auto Layout старается не принимать белую одежду за нижнее белое поле фотографии, но в сложных кадрах цвет всё равно может остаться неопределённым.

Если цвет определить не удалось, фотография остаётся в раскладке и просто не участвует полноценно в цветовой оптимизации.

# Совместное использование М/Д, позы и цвета

Все дополнительные правила можно включить одновременно.

При конфликте приоритет примерно такой:

1. фотография должна физически помещаться в выделение;
2. сохраняется корректная геометрия и общий масштаб;
3. сохраняется хорошее чередование М/Д;
4. учитывается направление человека;
5. среди допустимых вариантов улучшается цветовая композиция.

Поэтому включение цвета не должно разрушать уже удачное чередование мальчиков и девочек только ради более красивой палитры.

---

# Рамки и слои без лиц

Auto Layout можно использовать не только для портретов.

Если выбраны обычные цветные или графические рамки без лиц:

- геометрическая раскладка работает нормально;
- одиночные shape-слои остаются shape-слоями;
- нативные shape-слои не отправляются на анализ изображения и для них не создаются JPEG-превью;
- пол всё ещё может определиться по имени слоя;
- направление головы/корпуса определить нельзя;
- режим цвета одежды **не сортирует рамки по цвету самой рамки**.

Если несколько **растровых слоёв или Smart Object** подряд не дают ни пола по фотографии, ни позы, ни цвета одежды, Auto Layout понимает, что перед ним, вероятно, не обычные портреты, и прекращает дальнейший покадровый анализ через Python до конца этого запуска. Shape-слои в этот счётчик не входят. Оставшиеся объекты раскладываются по геометрии без лишней обработки.

Данные, которые уже удалось получить ранее — например пол по имени слоя — сохраняются.

# Объединять каждый ряд в группу

Если включено, после раскладки каждый готовый ряд помещается в отдельную группу Photoshop.

Это удобно для последующего ручного редактирования целого ряда.

После успешной раскладки Auto Layout автоматически выполняет **Collapse All Groups**, если использовались исходные группы или создавались группы рядов. Палитра Layers остаётся компактной. Команда сворачивает все группы документа, а не только созданные Auto Layout.

Если выключено, слои остаются без дополнительной группировки. Если исходных групп среди раскладываемых объектов не было, Auto Layout не вызывает Collapse All Groups.

# Запись в экшен

Auto Layout можно записывать в Photoshop Action и применять к серии однотипных листов. При воспроизведении используются настройки, записанные непосредственно в шаг Action; текущие глобальные настройки Auto Layout их не подменяют.

## Обычная запись

Если **«фиксировать отступы и трансформацию»** выключено, Action запоминает выбранные режимы и параметры, но на каждом новом листе Auto Layout **заново рассчитывает масштаб и фактические интервалы** под текущее количество фотографий, их размеры и текущее выделение.

Используйте этот режим, если на каждом листе нужно заново подбирать размеры фотографий под доступное место.

## Фиксировать отступы и трансформацию

В версии **0.10.19** Action с включённой фиксацией сохраняет **типичную высоту объектов в пикселях**, общий горизонтальный интервал X и общий вертикальный интервал Y. Количество фотографий и распределение по рядам могут меняться. Состав выбранных слоёв и их ID не записываются.

1. Подготовьте типовой, желательно наиболее заполненный лист серии.
2. Включите запись Action и запустите Auto Layout.
3. Включите **«фиксировать отступы и трансформацию»** и выполните раскладку.
4. Проверьте результат и остановите запись.
5. Применяйте Action к следующим листам, выделяя нужные фотографии и область раскладки.

Профиль записывается только после успешного применения. Редактирование шага Action меняет настройки без перестановки слоёв. Чтобы включить фиксацию в обычном ранее записанном шаге, запишите шаг заново.

### Горизонтальные интервалы

Во всех четырёх режимах выравнивания фиксированный Action использует **один сохранённый X-интервал**. При записи «По ширине» берётся минимальный фактический интервал среди рядов с несколькими фотографиями, и уже лист записи приводится к этому общему интервалу. Если таких рядов нет, сохраняется минимальный расчётный интервал.

При включённой фиксации **«По ширине» центрирует ряды**, оставляя свободное место по краям. Одновременно сохранить размеры рамок, интервалы и растяжение до обеих границ при произвольном количестве фото невозможно. Без фиксации «По ширине» по-прежнему растягивает каждый ряд до границ площадки.

Y — расстояние между нижней границей самого высокого объекта предыдущего ряда и верхней границей следующего ряда внутри площадки. Если на листе записи соседних рядов нет, для будущих листов сохраняется минимальный расчётный Y-интервал. Пустые промежутки между отдельными площадками определяются самим выделением.

### Размеры рамок и ограничения

- Опорная высота — **медиана** измеренных высот: у нечётного числа объектов это среднее по порядку значение, у чётного — среднее двух центральных. При записи сохраняется медиана итоговых высот.
- При воспроизведении единый масштаб = сохранённая высота / медиана высот текущих исходников. Все объекты масштабируются одинаково; их небольшие исходные различия сохраняются.
- Несколько выступающих подписей или декоративных элементов не определяют медиану, если большинство объектов имеет одинаковую высоту. Отличия ширины на выбор масштаба не влияют.
- Скрипт измеряет границы объекта `boundsNoEffects` (у подготовленных групп — границы временного proxy). Внутреннюю фоторамку отдельно не выделяет. Если изменится типичная высота большинства объектов или будет выбран очень небольшой нетипичный поднабор, общий масштаб тоже изменится. Фиксация не делает все внешние габариты одинаковыми.
- Фактическая ширина и высота каждого объекта по-прежнему участвуют в проверке размещения. Большая подпись может потребовать другого распределения по рядам. Если набор не помещается при выбранном масштабе и сохранённых X/Y, раскладка останавливается без автоматического уменьшения.
- М/Д, поза и цвет могут менять порядок фотографий, сохраняя зафиксированные метрики. На воспроизведении фиксированного экшена используется JSX-упаковка с абсолютными ограничениями; Python не пересчитывает масштаб ради плотности. При первоначальной записи Python может участвовать в обычном поиске.
- Единицы фиксации — **пиксели**, не миллиметры. Для одинаковых печатных размеров документы должны иметь одинаковое разрешение печати.
- После применения проверяются фактические границы Photoshop. Для растров предусмотрен допуск около одного пикселя на границу/размер; субпиксельная идентичность растров не гарантируется. Большие отклонения вызывают откат. У групп проверяется аффинная трансформация исходных границ; визуальные границы временного proxy рассчитываются из неё.
- **Старые фиксированные экшены необходимо записать заново.** Старые профили без опорной медианной высоты не принимаются. Зависимости Python не изменились — достаточно заменить JSX и PYW.

# Практические рекомендации

### Для обычного группового листа

Начните с:

- автоматического количества рядов;
- вертикального ритма **«Авто»**;
- выравнивания **«По центру»**;
- минимальных интервалов X/Y;
- Python-заполнения выключенного.

Затем при необходимости добавьте М/Д, направление позы или цвет.

### Для сложного листа с местами под подписи и учителя

Создайте составное прямоугольное выделение с нужными вырезами и включите **«Рассчитывать заполнение площадок в Python»**.

### Для классической школьной группы

Полезная комбинация:

- автоматические ряды;
- **«Шире к центру»** или чередование длинного/короткого ряда;
- **«Чередовать мальчиков и девочек»**;
- **«Учитывать разворот тела и головы»**;
- при необходимости **«Согласованные цвета»**.

### Для рамок, карточек или других объектов без людей

Оставьте дополнительные фото-анализы выключенными. Используйте только геометрию, количество рядов, ритм и интервалы.

# Важные ограничения

- Все выбранные объекты масштабируются с **одним общим коэффициентом**.
- Внутри ряда объекты выравниваются по верхнему краю.
- Auto Layout не кадрирует фотографии и не меняет их содержимое.
- Скрипт не зеркалит людей ради композиции.
- Выделение должно состоять из прямоугольной геометрии без диагоналей и кривых.
- Цветовой режим анализирует одежду, но не предназначен для сортировки произвольных цветных рамок.
- Нейросетевой анализ помогает с композицией, но не является безошибочным. Неопределённый результат безопаснее ошибочной принудительной классификации, поэтому часть фотографий иногда остаётся без пола, позы или цвета.
- Для сложного составного выделения может существовать несколько почти равнозначных раскладок. Python проверяет больше вариантов, но не гарантирует математически идеальный результат для любого возможного макета.

# Отмена и повторная настройка

Во время работы можно нажать **Esc**. Auto Layout прекращает текущую операцию и старается вернуть документ к состоянию до запуска.

Настройки обычного запуска сохраняются между запусками после успешного подтверждения диалога.

Если результат не понравился, обычно достаточно отменить действие Photoshop, изменить параметры Auto Layout и запустить его снова.
