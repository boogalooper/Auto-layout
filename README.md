# Auto Layout для Photoshop

Auto Layout размещает выбранные фотографии или рамки внутри выделения: подбирает ряды, общий масштаб и расстояния между объектами. Скрипт рассчитан прежде всего на школьные и групповые макеты.

Все объекты масштабируются одинаково и выравниваются по верхнему краю ряда. Обычная раскладка работает без Python. Он нужен для алфавитной сортировки, анализа людей и одежды, а также расширенного поиска заполнения сложных площадок.

## Установка

Распакуйте архив в обычную папку. Скопируйте содержимое `Photoshop-files` в папку сценариев Photoshop, например:

```text
C:\Program Files\Adobe\Adobe Photoshop 2026\Presets\Scripts\
```

В ней должны оказаться `Auto-layout.jsx` и папка `lib` с файлом `auto-layout-api.pyw`. Оставьте одну актуальную копию скрипта и перезапустите Photoshop.

Для дополнительных функций запустите `install_runtime.bat`. Выберите **Normal secure mode**; если Kaspersky мешает загрузке пакетов — **Kaspersky compatibility**. Дождитесь сообщения **Installation complete**. Установщик подготовит отдельный Python и необходимые модели; системный Python настраивать не нужно.

При обновлении заменяйте JSX и PYW файлами из нового архива. Повторная установка Python нужна только при изменении зависимостей.

## Первый запуск

1. Подготовьте фотографии или рамки и снимите блокировки с перемещаемых слоёв.
2. Инструментом **«Прямоугольная область»** выделите место для раскладки.
3. Выберите нужные слои в палитре Layers.
4. Запустите **Файл → Сценарии → Auto Layout**.
5. Настройте раскладку и нажмите **«Разложить слои»**.

Для начала подойдут автоматическое количество рядов, ритм **«Авто»** и выравнивание **«По центру»**. Затем можно добавить чередование М/Д, учёт позы или цветовую расстановку.

Выделение может состоять из нескольких отдельных прямоугольников, содержать отверстия и вырезы. Так можно оставить место для учителя, заголовка или декора. Создавайте форму добавлением и вычитанием прямоугольных областей: диагонали, кривые и лассо не поддерживаются.

## Подготовка слоёв

Поддерживаются пиксельные слои, Shape Layers, Smart Objects, группы и связанные слои. Группа или связанный набор рассматривается как один объект. Скрипт временно создаёт Smart Object для измерения и анализа, а итоговую раскладку применяет к исходным слоям, сохраняя их структуру и связи. Текст внутри объекта используется для определения имени.

Связанные слои должны находиться в одном контейнере. Корректирующие слои и обтравочные маски внутри группы должны действовать только на её содержимое. Если набор нельзя безопасно обработать, скрипт остановится. Background предварительно преобразуйте в обычный слой.

## Настройки раскладки

**Количество рядов.** Автоматический режим выбирает подходящую структуру и старается получить крупные фотографии без неудачных одиночных рядов. Чтобы задать число рядов вручную, снимите галочку автоматического подбора.

**Вертикальный ритм.** Можно предпочесть более широкие ряды к центру или к краям, а также чередовать длинные и короткие ряды. Ритм помогает выбрать композицию, но не отменяет ограничения размеров и формы выделения.

**Выравнивание.** Ряды можно разместить слева, по центру, справа или по ширине. В режиме **«По ширине»** расстояния между фотографиями рассчитываются отдельно для каждого ряда, чтобы заполнить площадку от края до края. В остальных режимах используется общий горизонтальный интервал. Если при выбранном масштабе и допустимых интервалах весь блок уже площадки, он автоматически центрируется. Короткие ряды сохраняют выравнивание слева или справа внутри блока. Свободное место сверху и снизу также распределяется поровну, насколько позволяет форма выделения.

**Интервалы X/Y.** Минимальные расстояния задаются в процентах от типичной высоты объектов. Параметр максимального увеличения позволяет расширять их до ×2, ×3 или ×4 при наличии свободного места. В режиме «По ширине» этот предел действует только на вертикальный интервал.

**Группировка рядов.** Каждый готовый ряд можно поместить в отдельную группу для дальнейшего редактирования. После работы с группами скрипт сворачивает группы в палитре Layers.

**Не увеличивать размер слоёв.** Ограничивает общий масштаб текущими размерами фотографий: максимум 100%. Уменьшение для вписывания остаётся разрешённым. Настройка действует в JSX и Python и сохраняется в экшенах. Если фиксированный экшен требует увеличения, скрипт остановится с объяснением.

## Дополнительные режимы

**Заполнение площадок в Python** включает расширенный поиск. Если одновременно включены М/Д, поворот или цвет одежды, Python подбирает также структуру и состав рядов по всему набору фотографий — в том числе в обычном прямоугольнике. Приоритет: допустимая геометрия и заполнение → М/Д → поворот → цвет одежды. Ради лучшей композиции разрешено уменьшить линейный размер фотографий максимум на **1% от лучшего найденного масштаба** (это примерно 2% площади). При заданном числе рядов оно сохраняется; экшены с фиксацией размеров и интервалов этот поиск не используют.

Поиск ограничен числом вариантов и бюджетом около 14 секунд, обычно заканчивается раньше. Анализ фотографий и операции Photoshop выполняются отдельно. При исчерпании бюджета сохраняется лучший найденный допустимый вариант; если Python не вернул корректную раскладку, используется JSX. Без галочки Python работает прежний быстрый решатель.

**Чередование мальчиков и девочек** строит схему М/Д внутри рядов и по возможности между ними. При дисбалансе скрипт старается сохранить симметрию и расположить меньшинство ближе к центру. Пол сначала определяется по имени слоя, затем при необходимости — по фотографии.

**Учёт разворота тела и головы** помогает размещать портреты так, чтобы композиция была обращена к центру листа. Фронтальные фотографии предпочитают центр, сильные повороты — края. Эта настройка меняет порядок фотографий; сами изображения не поворачиваются и не зеркалятся.

**Цвет одежды** учитывается по всему листу, включая перестановки между рядами и площадками. При Python-заполнении он участвует также в выборе структуры рядов, в том числе когда М/Д и поворот выключены. Режим **«Согласованные цвета»** сближает похожие палитры, а **«Максимальный контраст»** усиливает различия соседей.

М/Д, позу и цвет можно использовать вместе. Геометрия имеет первый приоритет, затем — чередование М/Д, направление человека и цвет. Анализ может ошибаться или оставлять часть данных неопределёнными, поэтому результат стоит оценить визуально.

Для рамок и других объектов без людей используйте обычную геометрию. Цветовой режим оценивает одежду, а не цвет самой рамки. Пол и алфавитный порядок всё ещё могут определяться по названиям слоёв.

## Сортировка по алфавиту

В разделе «Дополнительно» доступны два режима:

- **По алфавиту в пределах страницы** — сквозной порядок для всех объектов. Сначала заполняется первая зона, затем следующая; внутри зоны — сверху вниз, в ряду слева направо.
- **По алфавиту в пределах зоны** — фотографии остаются в своих площадках и сортируются отдельно внутри каждой.

Зона — прямоугольная площадка, которую скрипт получил из выделения. Сложная форма с вырезами может содержать несколько таких площадок.

Для сортировки нужен Python. Он читает названия слоёв и выделяет имя и фамилию, пропуская числовые индексы и обычные приписки вроде «копия», «дубль» или IMG-номера. Порядок слов сохраняется:

```text
023 Иванов Иван — копия  →  Иванов Иван
023 Иван Иванов — копия  →  Иван Иванов
```

Названия слоёв не меняются. Регистр не влияет на сравнение, Ё считается Е. При одинаковых ключах сохраняется порядок палитры; слои без буквенной подписи идут в конце. Для редких имён и необычных приписок разбор может быть неточным, поэтому лучше давать слоям понятные названия.

Алфавитный режим блокирует Python-заполнение, М/Д, позу и цвет. После его отключения прежние настройки снова доступны. При недоступном Python сортировка остановится с сообщением.

## Приоритеты по цветовым меткам

В списках **«В начале листа»** и **«В конце листа»** выберите метки нужных фотографий. Скрипт разместит сначала первую категорию, затем остальные фото, затем последнюю. Порядок сквозной: первая зона, следующая зона; внутри зоны — сверху вниз, в ряду слева направо. Граница категорий может проходить посреди ряда.

Внутри каждой категории действует обычный подбор по М/Д, повороту и одежде либо выбранная алфавитная сортировка. Приоритеты работают в JSX и Python, сохраняются в настройках и экшенах. Если выбранных меток нет, скрипт продолжает обычную раскладку без предупреждений. Если все фото одной категории, раскладка остаётся обычной; при разделении 50/50 две категории идут подряд без пустой середины.

**«Не задано»** отключает категорию, а **«Без цветовой метки»** выбирает непомеченные объекты. Для начала и конца нужны разные метки. У группы учитывается её собственная метка; у связанного набора — метки корневых слоёв. Конфликт начала и конца внутри одного набора нужно устранить перед запуском.

## Работа с экшенами

Auto Layout сохраняет настройки в шаг Photoshop Action. Обычный экшен на каждом листе заново подбирает масштаб и интервалы под текущее количество фотографий и выделение.

Для серии с одинаковым размером рамок включите **«Фиксировать отступы и трансформацию»**. Запишите шаг на типовом, желательно наиболее заполненном листе. После успешной раскладки экшен сохранит типичную высоту объектов и интервалы X/Y. На следующих листах количество фотографий может меняться, а общий масштаб будет подбираться под сохранённую высоту.

Типичная высота определяется по медиане, поэтому несколько выступающих подписей не задают масштаб всей страницы. При этом измеряются внешние границы объектов: если высота большинства изменится, общий масштаб тоже скорректируется. Все реальные габариты продолжают учитываться при размещении.

С фиксацией режим **«По ширине»** центрирует ряды с единым сохранённым горизонтальным интервалом. Если фотографии или выбранный алфавитный порядок не помещаются при сохранённых размерах и отступах, скрипт остановится, не уменьшая их ради заполнения.

Фиксация выполняется в пикселях; для одинакового размера при печати используйте одинаковое разрешение документов. Растровые границы могут округляться примерно на один пиксель.

Редактирование шага Action меняет его настройки без перестановки слоёв. Чтобы добавить фиксацию в обычный шаг, запишите его заново. Фиксированные экшены из версий до 0.10.19 также нужно перезаписать.

## Отмена и повторная настройка

Во время работы нажмите **Esc**, чтобы прервать операцию и вернуть документ к исходному состоянию. Если результат не понравился, отмените раскладку в Photoshop, измените параметры и запустите скрипт снова. Настройки сохраняются между запусками.

Подробные изменения версий находятся в `CHANGES.md`, результаты проверок и ограничения — в `AUDIT.md`.
